# Card Manager Pro 設計ドキュメント

本システムを保守・改修する人向けの資料です。初めての方は 01 → 04 の順に読んでください。

| 文書 | 内容 | 主な読者 |
|---|---|---|
| [01_基本設計書](01_基本設計書.md) | 目的・範囲、利用者と権限、システム構成、機能・画面一覧、非機能要件 | 全員 |
| [02_詳細設計書](02_詳細設計書.md) | ディレクトリ構成、API層、テーブル・DB関数・権限、検索仕様、処理フロー | 開発者 |
| [03_改修ログ](03_改修ログ.md) | 改修の履歴（DB変更と反映手順を含む）と記録ルール | 全員（改修のたびに追記） |
| [04_運用手順書](04_運用手順書.md) | 環境構築、SQLの反映手順、バックアップ、トラブル対応 | 運用担当 |
| [05_改善提案とロードマップ](05_改善提案とロードマップ.md) | 既知の課題、追加機能の候補、複数オーナー対応への拡張案 | 企画・開発者 |
| [06_フレームワーク更新計画](06_フレームワーク更新計画.md) | Node.js 24 / React 19 / Next.js 16 への段階的な更新計画と確認リスト | 開発者 |

## 更新のルール
- コードやDBを変えたら、関係する文書も同じコミットで更新する。
- DB変更は必ず [03_改修ログ](03_改修ログ.md) に「実行したSQL」と「SQLとデプロイの順番」を残す。
