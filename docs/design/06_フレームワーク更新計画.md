| 課題 | 状況 | 対応案 |
|---|---|---|
| 開発用依存の `npm audit`（16件, moderate） | eslint 9 本体と eslint-plugin-react・import・jsx-a11y が `minimatch` 3.1.5 に依存（修正版は 11.0.1 以降のみ）。開発用ツールだけで、本番には含まれない。本番依存は0件 | **A（推奨）**: 上流の対応を待ち、依存更新のたびに見直す。B: `overrides` で 11 に上げる（3系と API が違い lint が壊れる見込み。非推奨）。C: ESLint 10（プラグイン未対応）。`npm audit fix --force` は eslint を 4.0.0 に戻すため使わない。**方針は相談中** |

| `next/font`（Google Fonts）の取得エラー | 段階2のプレビューで1回発生し、キャッシュなしの Redeploy で解消。以後は再発なし | 再発時はキャッシュなしで Redeploy。繰り返すなら `next/font/local` でフォントを自前で置く方式を相談する |
